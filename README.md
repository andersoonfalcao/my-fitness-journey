# My Fitness Journey

Quero fazer um aplicativo web para acompanhar alimentação (contagem de macros e calorias) e acompanhar a evolução do meu peso.
Também quero uma parte para treinos, mas sem eu precisar adicionar manualmente: com base em algum método estruturado para entender meu objetivo (meta de peso, foco), o app deve me criar um plano de treinos trazendo os exercícios recomendados.
Preciso poder trocar qualquer exercício caso eu não queira fazer ou falte o equipamento na minha academia.
E cada exercício precisa ter uma ilustração visual mostrando como executar o movimento, além de instruções de postura.
